# Telas do app — captura para revisão de design (2026-07-16)

Capturas de **todas as telas** do app Vinc, tiradas rodando o app no navegador
(React Native + `react-native-web`) em **modo demonstração** (dados de exemplo),
viewport de celular (390×844 @2x).

## ⚠️ Duas observações antes de olhar

1. **A faixa laranja "Modo demonstração — dados de exemplo"** no topo de cada
   imagem é **só do modo de captura** (sem backend configurado). **Não existe no
   app real** — pode ignorar no design.
2. **`31-avaliar.png` está em branco** porque a tela "Avaliar" precisa de um
   serviço **concluído real** para preencher; no modo demo os dados não existem.
   Não é um bug de design.
