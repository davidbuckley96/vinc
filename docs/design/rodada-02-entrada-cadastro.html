Opção A — Tela única clássica

e-mail + senha

Tudo em uma tela: e-mail, senha, entrar ou criar conta. Familiar e rápido para quem já usa apps, porém o formulário inteiro de uma vez pode intimidar quem tem pouca prática.

Opção B — Passo a passo · recomendada

e-mail + senha, uma pergunta por tela

Cadastro em 3 telas curtas (nome → e-mail → senha), uma pergunta por vez, letra grande e botão único — o padrão do WhatsApp. É o fluxo mais amigável para baixa escolaridade e vira mais telas, porém cada uma é trivial.

Opção C — Social primeiro

Google + e-mail

Um toque para entrar com a conta Google (que quase todo Android já tem), com e-mail como alternativa. Menos fricção de senha, mas exige configurar o login Google (e Apple, para publicar no iOS) — um pouco mais de setup e dependência.
